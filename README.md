## 🛠️ Local Machine Setup & Testing

### 1. Prerequisites
- **Node.js** (v18 or higher recommended)
- **npm** or **pnpm** or **bun**

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000` (or `http://localhost:5173`).

### 4. Build for Production
```bash
npm run build
```

### 5. Preview Production Build
```bash
npm run preview
```

## 🌐 Deployment

### Deploying to Vercel
1. Push this repository to your GitHub account: `https://github.com/Fk4111/faiyaz-khan-portfolio`.
2. Connect your repository on [Vercel](https://vercel.com).
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**!

### Deploying to Netlify
1. Drag and drop the `dist/` folder into Netlify, or connect via Git.
2. Build command: `npm run build`
3. Publish directory: `dist`
